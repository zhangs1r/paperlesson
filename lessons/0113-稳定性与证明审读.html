平均误差不跑偏，就代表估计稳定吗？

先认清保证对象，再读 Lemma 3、Theorem 3 与证明中的近似

0113建议 30 分钟难度 ★★★★☆对应原文 §4.2、Lemma 3、Theorem 3、附录
本课目标与前置知识

前置：0111 课的随机凸组合与矩阵修正项。需要期望、矩阵求逆的基础；半正定序与 Lyapunov 量在本页速成。学完要能回答：① 一阶矩有界与均方误差有界差别在哪？② Lemma 3 把信息矩阵"夹"在什么之间？③ Theorem 3 的证明主线是什么、哪里用了近似？④ 论文证明里有哪些需要标注的出入？

1. 先用靶心图消除一个误会

想象两位射手：两人的子弹平均落点都在靶心，但一位弹孔集中，另一位散得很开。只看平均落点，你无法判断谁更准。估计误差的正负抵消也有同样的问题。

拖动看看：同样的"平均值"，完全不同的精度

两个射手的平均误差都是 0——但其中一个是"平均出来的假象"。

两边平均误差都是 0（正负抵消），但均方误差相差 100 倍。论文 Theorem 3 的定理本体保证的是平均误差（一阶矩）有界——这正是容易被误读的地方。

三个容易混淆的量 $$\big\|\mathbb E[e]\big\|\quad\ne\quad \mathbb E\big[\|e\|\big]\quad\ne\quad \mathbb E\big[\|e\|^2\big].$$

是什么：依次是"平均误差的范数"、"误差范数的期望"、"均方误差"。

直觉：先平均（正负可能抵消）→ 数值小；先取长度或平方（不抵消）→ 数值大。

细节：恒等式 $\mathbb E[\|e\|^2]=\operatorname{tr}(\operatorname{Cov}(e))+\|\mathbb E[e]\|^2$ 说明——均值只控制其中一项，控制不了方差那一项。想从一阶矩结论推出二阶矩结论，中间有实质距离。

论文原文的措辞需要标注

Theorem 3 的公式明确写的是 $\|\mathbb E[\hat e_k^i]\|$ 一致有界（一阶矩、平均误差）。但它前一段的引导语却用了 "mean square estimation errors"（均方估计误差）的措辞。课程按定理公式所述对象理解——平均误差有界——不把措辞冲突悄悄合并成"均方稳定"的更强保证。这是阅读理论论文时的常见陷阱：定理陈述优先于正文措辞。

2. 两个数学工具速成

半正定序：不是逐个元素比大小

矩阵不等式 $F\le G$（$F,G$ 同阶对称）读作：任意方向 $z$ 上都有 $z^\top Fz\le z^\top Gz$。它比较的是"二次型"，不是逐元素比大小。

半正定序的等价表述 $$-\delta I\le E\le\delta I\quad\Longleftrightarrow\quad |z^\top Ez|\le\delta\|z\|^2\quad\text{for all }z.$$

直觉：上界 $G=F+\delta I$ 的意思是"所有方向都留出同样的余量 $\delta$"，不是"只允许对角线有误差"。0.109 课的 $\frac{n}{2\mathcal Q}I$ 就是这么来的：任何方向的量化扰动幅度都被 $\frac{n}{2\mathcal Q}$ 兜住。

细节（重要换算）：对对称误差矩阵，若每个元素的绝对误差 ≤ $\frac{1}{2\mathcal Q}$，其谱范数可被 $\frac{n}{2\mathcal Q}$ 控制（$n$ 是维数）。这是"元素级误差 → 矩阵级界"的标准放大。

Lyapunov 量：把误差装进一把"有刻度的尺"

普通的欧氏长度 $\|e\|$ 把所有方向一视同仁；而带信息矩阵的二次型 $e^\top\Omega e$ 按方向的重要性加权——不确定的方向权重大，确定的方向权重小。它就像一把"有刻度的尺"：只要信息矩阵始终有正的上下界（不会缩到零、也不会涨到无穷），尺子就始终能工作，误差长度就被它"卡"住。

Lyapunov 量（论文式 (11) 的核心对象） $$V_k^i\triangleq \mathbb E[\bar e_k^i]^\top\bar\Omega_{k,i}^{p}\,\mathbb E[\bar e_k^i],\qquad \bar e_k^i\triangleq\bar x_{k,i}^{p}-x_k.$$

读法（必须仔细）：先求平均误差 $\mathbb E[\bar e_k^i]$，再用信息矩阵加权。注意不是 $\mathbb E[e^\top\Omega e]$——那个会涉及二阶矩。论文构造的是前者，与 Theorem 3 的一阶矩口径一致。

3. 四个假设各自负责什么？

假设内容在证明里负责什么
A1无向图连通，$W$ 行随机且有自权重信息能沿路径传播；融合是"加权平均"而不是越乘越小。注意：连通不等于"一步到全网"。
A2动力学/观测有界，$P_0,Q,R$ 有正定上下界，编码尺度与 $H$ 有上界给信息矩阵的上界提供常数来源。它不代替密码学模数范围检查——那是实现层的事。
A3系统联合可观估计问题本身有解的前提。注意是"联合"可观：各节点合起来够，不等于单节点自己够。
A4$\inf_k\lambda_{\min}\{A_kA_k^\top\}\ge\beta>0$保证 $A_k$ 的逆"不会越来越病态"——比"每步可逆"更强。

这四条是充分条件框架，不是"任何能工作的估计器都必须逐条满足"的必要条件。把它们迁移到机器人模型时，每条都要重新核对。

4. Lemma 3：先把信息矩阵"夹"住

原文 Lemma 3 · 信息矩阵的上下界 $$\underline\omega I\ \leq\ \hat\Omega_{k,i}^{p}\ \leq\ \overline\omega I,\qquad 0<\underline\omega\le\overline\omega.$$

是什么：所有时刻、所有节点的融合后信息矩阵，被一对公共常数夹住（证明在论文附录）。

直觉：既不会"瘦到求逆失控"（有正下界），也不会"胖到拥有无限信息"（有上界）。

细节（边界）：这是算法内部信息矩阵的界——不能直接认作"真实误差协方差已被证明一致有界"。

"夹住"是什么意思：拖着看椭圆

信息矩阵决定误差椭圆的形状。拖动看它被上下界限制住的区间。

45%

拖动时注意：实际的信息矩阵（金色）可以变化，但被卡在绿色下界和橙色上界之间——永远出不去。这正是 Lemma 3 说的事：$\underline\omega I\le\hat\Omega\le\overline\omega I$。它给 Theorem 3 提供了"尺子不会坏掉"的保证。

附录里的证明走两条路：

  1. 上界路径：预测步用过程噪声给出信息上限；量测更新增加的 $C^\top R^{-1}C$ 由 A2 控制；凸组合与有限的量化修正不会让上界失控。三块相加得到 $\overline\omega$。
  2. 下界路径：用 Lemma 1 和正向修正，把新矩阵的下界接到"理想的随机凸组合"上；再借助连通性、联合可观性与已有的分布式滤波结果（引用了 Battistelli 等人的工作）完成。原文对后一部分只写了"类似程序，从略"。
读证明时的诚实态度

下界的末段是引用已有结果，不是本论文逐行证明的——读者应当知道这一点，而不是以为"只靠一行求和就完成了证明"。这不算缺陷（引用标准结果在数学论文里很常见），但汇报时别把它说成"论文从零证明了全部"。

5. Theorem 3：主线与必须标注的细节

定理总体：在 Assumptions 1–4 下，只要 $\mathcal Q_k^i$ 取得足够大、初始误差有界，就有 $\|\mathbb E[\hat e_k^i]\|\le\epsilon$ 对所有 $k$ 成立——平均误差一致有界。

证明的四个台阶（点着看）

原文式 (12) · 有效权重（含课程标注） $$\theta_k^{ii}=w_{ii}+\sum_{j\ne i}w_{ij}\lambda_k^{ij},\qquad \theta_k^{ij}=w_{ij}(1-\lambda_k^{ij})\quad(j\ne i).$$

课程按 Algorithm 3 展开的系数：邻居贡献是 $1-\lambda$，这样每行仍和为 1（与"加权平均"一致）。

原文出入标注：PDF 第 7 页式 (12) 原样写的是非对角项 $w_{ij}\lambda_k^{ij}$，与 Algorithm 3 中邻居项系数 $w_{ij}(1-\lambda_k^{ij})$ 不一致（第 0111 课已标注过一次）。课程给出的是与算法代数一致的展开——不宣称作者已发布勘误，只标出所见。

原文式 (15) 末的收缩递推 $$V_{k+1}\preceq\tilde\gamma\,\Theta_kV_k,\qquad 0<\tilde\gamma<1.$$

读法：这是论文试图建立的收缩形式。注意 $V_k$ 是"各节点标量能量"组成的向量，所以此处的 $\preceq$ 是逐元素比较（和矩阵的半正定序不同）。若权重非负且行和为 1，一行加权值不超过上一时刻的最大值——这给出统一界。

近似与随机性：精读不能跨过去

原文在式 (13) 前使用了"编码尺度足够大，所以量化往返 ≈ 原量"这一步。但有三个问题需要坦白标注：① 有限精度误差项与矩阵修正怎样传入严格不等式，并未在这段逐项保留；② 随机混合使信息矩阵本身成为随机量，期望与矩阵运算之间的交换需要说明"是否条件于协议随机量"；③ 前面提过的式 (12) 系数出入。课程展示作者的证明思路，但不把"修好一处系数和一个 ≈ 号"当作"已补齐有限精度的完整证明"。

6. 汇报时怎么说

把这一课学到的"精确表述"组装成一段可以用于组会的话：

推荐表述模板

"作者在四个假设下给出信息矩阵的上下界，并以平均误差的加权二次型讨论有界性。定理本体是一阶矩结论；证明中的有效权重表达与有限量化近似还需要仔细核对。仿真中的 AMSE 曲线是另一层数值证据，不是定理的直接推论。"

这段话的好处：保留论文的真实贡献（有界性分析、矩阵界），又不替作者扩张结论（不说"证明了均方稳定"）。

7. 合上正文，试着回答

练习一：均值陷阱

误差等概率为 $+k$ 或 $-k$，均值是否有界？均方误差呢？由此说明什么？

展开答案与解释
均值恒为零 → 有界；均方误差为 $k^2$ → 随 $k$（或时间）增大。结论：一阶矩有界推不出二阶矩有界。这正是 Theorem 3 与本课靶心图想让你记住的核心区别。

练习二：有效权重手算

自身权重 $w_{ii}=0.5$、邻居权重 $w_{ij}=0.5$、$\lambda=0.3$。按 Algorithm 3 的版本展开，自身与邻居系数各是多少？验证行和。

展开答案与解释
自身系数 $=w_{ii}+w_{ij}\lambda=0.5+0.5\times0.3=0.65$；邻居系数 $=w_{ij}(1-\lambda)=0.5\times0.7=0.35$；行和 $=0.65+0.35=1$ ✓。如果误把邻居项也乘 λ（按原文式 (12) 的字面写法），行和会只有 $0.5+0.15=0.65$——这不是同一个融合式，凸组合的工具也就用不上了。

练习三：哪一个结论还缺证据？

「量化误差很小、信息矩阵可逆」——这两条是否已经足以证明真实均方误差一致有界？

展开答案与解释
不够。还需要处理：随机误差递推的二阶矩（噪声项、有限量化误差传入期望运算的方式）、随机权重带来的条件性问题等。"可逆"与"内部矩阵界"不能替代对真实误差统计量的分析——Lemma 3 是算法内部量的界，不是真实误差协方差的界。
本课带走的一句话

理论课最重要的能力是辨认"证明了哪个对象"：Theorem 3 证明的是平均误差（一阶矩）有界，不是均方误差；Lemma 3 给出的是算法内部信息矩阵的界，不是真实误差协方差的界；证明主线清晰（预测收缩 → 融合放缩 → 量测不增能量 → 全网递推），但式 (12) 系数出入与"量化足够大 ⇒ ≈"的处理需要标注。读证明，读的是"到哪儿为止"。

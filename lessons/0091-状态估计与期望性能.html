状态估计与期望性能分析

合法用户和窃听者分别怎么估计状态？马尔可夫链模型如何刻画长期性能？

🎯 主题：远程估计 · 马尔可夫链 · 稳态分析 🧭 入口：Section 4-5
合法用户估计 窃听者估计 马尔可夫链模型 期望稳态性能

本节目标

理解编码方案激活后，合法用户和窃听者各自的状态估计方程和误差协方差演化，以及为什么窃听者会"中毒"。

和上一节怎么接

上节课我们设计了编码方案（什么时候发噪声），这节课看这个方案对两个参与方的估计性能分别产生什么影响。这是分析篇的核心。

1. 合法用户的估计

合法用户知道伪随机指示器 $u_k$（提前约定）和检测变量 $\nu_k$（自己生成的），因此可以做出最优 MMSE 估计：

$$\hat{x}_k = \begin{cases} \hat{x}_k^s, & \text{若 } (\lambda_k, u_k) = (1, 1) \\ A\hat{x}_{k-1}, & \text{若 } \lambda_k = 0 \text{ 或 } (\lambda_k, u_k) = (1, 0) \end{cases}$$

对应误差协方差：

$$P_k = \begin{cases} \bar{P}, & \text{若 } (\lambda_k, u_k) = (1, 1) \\ AP_{k-1}A^\top + Q, & \text{若 } \lambda_k = 0 \text{ 或 } (\lambda_k, u_k) = (1, 0) \end{cases}$$

关键：合法用户在收到噪声包时（$\lambda_k=1, u_k=0$）不会用噪声更新估计，而是直接做开环预测——噪声对它无效。

2. 窃听者的估计（Lemma 1）

窃听者不知道编码方案——它认为收到的每个包都是状态估计值。这是整个方案能奏效的前提假设。

$$\hat{x}_k^e = \begin{cases} \hat{x}_k^s, & \text{若 } (\lambda_k^e, u_k) = (1, 1) \\ n_k, & \text{若 } (\lambda_k^e, u_k) = (1, 0) \\ A\hat{x}_{k-1}^e, & \text{若 } \lambda_k^e = 0 \end{cases}$$

当窃听者收到噪声 $n_k$ 时，它误以为这是真实状态估计，直接同步进去。对应的误差协方差成为 Lemma 1 的核心：

$$P_k^e = \begin{cases} \bar{P}, & \text{若收到真实估计} \\ P_n = P^{OP} + \bar{P}, & \text{若收到噪声} \\ AP_{k-1}^e A^\top + Q, & \text{若丢包} \end{cases}$$

由于 $\bar{P} > 0$，因此 $P_n > P^{OP}$。这意味着：窃听者收到噪声后的估计误差比完全不用任何数据还大。

💡 数学直觉

$P_n = P^{OP} + \bar{P}$ 的推导很直观：收到噪声 $n_k$ 后，窃听者认为状态 = 噪声。真实状态 $x_k$ 和噪声 $n_k$ 不相关，所以误差协方差 = $\mathbb{E}[x_k x_k^\top] + \mathbb{E}[n_k n_k^\top] = P^{OP} + \bar{P}$。噪声越大（$\bar{P}$ 越大），窃听者的惩罚越重。

3. 马尔可夫链模型

由于传感器发完包后不知道谁收到了（没有 ACK），我们用期望来刻画长期性能。论文为两个参与方分别建立了马尔可夫链：

3.1 合法用户马尔可夫链（Lemma 2）

状态 $G_k = 0$ 表示收到真实估计，$G_k = j$ 表示连续 $j$ 次丢包/噪声。转移概率：

  • $G=0 \to G=0$：概率 $(1-\bar{\gamma})(1-\mu)$（收到且不是噪声）
  • $G=j \to G=j+1$：概率 $\bar{\gamma} + (1-\bar{\gamma})\mu$（丢包或收到噪声）

稳态分布：$\pi_j = (\bar{\gamma} + (1-\bar{\gamma})\mu)^j (1-\bar{\gamma})(1-\mu)$

3.2 窃听者马尔可夫链（Lemma 3）

窃听者的链多了一个特殊状态：$G_k^e = 1$ 表示收到噪声。转移概率（奇偶交替）：

  • $G=0 \to G=0$：$(1-\gamma^e)(1-\mu)$（收到真实估计）
  • $G=0 \to G=1$：$(1-\gamma^e)\mu$（收到噪声）
  • $G=j \to G=j+2$：$\gamma^e$（连续丢包翻倍）

4. 期望稳态性能

利用马尔可夫链的稳态分布和每个状态的条件期望，得到两个闭式结果：

Lemma 2：合法用户

$$\lim_{k\to\infty} \mathbb{E}[P_k] = (1-\bar{\gamma})(1-\mu)W + (\bar{\gamma}+(1-\bar{\gamma})\mu)S$$

其中 $W = L(\sqrt{\bar{\gamma}+(1-\bar{\gamma})\mu}\cdot A, \bar{P})$，$S = L(\sqrt{\bar{\gamma}+(1-\bar{\gamma})\mu}\cdot A, Q)$

Lemma 3：窃听者

$$\lim_{k\to\infty} \mathbb{E}[P_k^e] = (1-\gamma^e)(1-\mu)W^e + \gamma^e S^e + (1-\gamma^e)\mu H^e$$

其中 $H^e = L(\sqrt{\gamma^e}\cdot A, P_n)$——噪声项 $P_n$ 被编码进了这个解。

📝 课后思考

为什么窃听者的马尔可夫链设计成"奇偶交替"的结构？

因为窃听者的"收到噪声"（$G=1$）和"收到真实估计"（$G=0$）是两种不同"好"的状态，它们之后都会走向丢包。为了把"连续丢包数"和"最后一次收到的包类型"同时编码进状态，用奇偶来表示：偶数状态 = 最后一次收到真实估计后丢包，奇数状态 = 最后一次收到噪声后丢包。这样条件期望的计算更方便。

如果 $\mu=0$（从不发噪声），会怎样？

如果 $\mu=0$，合法用户和窃听者的方案都退化为标准远程估计（无编码）。合法用户的误差协方差只受丢包影响，窃听者的性能等于合法用户（因为两者收到相同的数据）。这时 $J^e(\mu) = J(\mu)$，隐私保护为零。所以 $\mu$ 必须大于 0 才有保护效果。

系统建模与卡尔曼滤波

离散时间线性系统是远程状态估计的"语言"，卡尔曼滤波是传感器的"大脑"。这节课把这两块基础打牢。
🎯 主题：状态空间模型 · Kalman 滤波 · Riccati 方程 📖 前置：线性代数 · 概率论

📋 前置知识 — 开始前请确认

本节假设你已经具备以下基础。如果感觉生疏，建议先快速回顾：

  • 线性代数：矩阵乘法、转置、逆矩阵、特征值分解、正定矩阵、迹 (trace)
  • 概率论：期望 $\mathbb{E}[\cdot]$、协方差 $\mathrm{Cov}(\cdot)$、高斯分布 $\mathcal{N}(\mu, \Sigma)$

💡 别被公式吓到 — 这节课所有的数学运算最终都归结为矩阵乘法和加减法。

1. 系统模型

我们研究的是离散时间线性时不变系统（Discrete-Time Linear Time-Invariant System）。它描述了一个物理过程如何随时间演化、我们如何观测它。

状态方程（系统怎么变）：

$$x_{k+1} = A x_k + w_k$$

观测方程（传感器看到什么）：

$$y_k = C x_k + v_k$$
$x_k \in \mathbb{R}^n$ — $k$ 时刻的系统状态（真实值，未知）
$y_k \in \mathbb{R}^m$ — $k$ 时刻的传感器观测值
$A \in \mathbb{R}^{n \times n}$ — 状态转移矩阵（描述系统动力学）
$C \in \mathbb{R}^{m \times n}$ — 观测矩阵（描述传感器如何"看"状态）
$w_k$ — 过程噪声，$w_k \sim \mathcal{N}(0, Q)$
$v_k$ — 观测噪声，$v_k \sim \mathcal{N}(0, R)$

噪声在干什么？

$w_k$ 表示系统建模的不确定性——比如风对无人机的影响、路面不平对小车的影响。
$v_k$ 表示传感器的测量误差——任何传感器都有噪声，这是物理限制。
两者都是 零均值高斯白噪声，且互不相关：$\mathbb{E}[w_k v_j^\top] = 0$ 对所有 $k,j$ 成立。

可检测性假设

论文假设 $(A, C)$ 可检测（detectable）。通俗来说：

  • 所有不可观测的模式都是稳定的（特征值都在单位圆内）
  • 系统不会出现"看不到却发散"的模式

这个假设很弱，绝大多数工程系统都满足。它的作用是保证后面 Kalman 滤波器能收敛到稳态。

2. Kalman 滤波器速成

论文中的智能传感器（smart sensor）内部运行着一个 Kalman 滤波器。它用观测 $y_k$ 来估计真实状态 $x_k$。

记传感器的估计值为 $\hat{x}_k^l$（上标 $l$ 代表"local"，即传感器本地估计），误差协方差为 $P_k^l$。

2.1 两步法：预测 + 更新

① 预测步（时间更新）

用系统模型"猜"下一步状态

$$\hat{x}_k^{l-} = A \hat{x}_{k-1}^l$$ $$P_k^{l-} = A P_{k-1}^l A^\top + Q$$

② 更新步（观测更新）

用实际观测来"修正"预测值

$$z_k = y_k - C \hat{x}_k^{l-}$$ $$K_k^l = P_k^{l-} C^\top (C P_k^{l-} C^\top + R)^{-1}$$ $$\hat{x}_k^l = \hat{x}_k^{l-} + K_k^l z_k$$ $$P_k^l = (I - K_k^l C) P_k^{l-}$$

💡 直观理解

预测：从上一时刻的状态，用物理规律 $A$ 外推下一步。不确定性因过程噪声 $Q$ 而增大。
更新：拿观测 $y_k$ 和预测值比较，差异叫创新（innovation）$z_k$。然后用 Kalman 增益 $K_k^l$ 来决定"信观测多少、信预测多少"。更新后不确定性缩减。

2.2 关键角色：卡尔曼增益 $K_k^l$

$K_k^l$ 是 Kalman 滤波器的核心——它是一个加权矩阵，负责在预测和观测之间做最优权衡：

  • $K_k^l$ 越大 → 越信任观测（观测噪声 $R$ 小，或预测误差 $P_k^{l-}$ 大）
  • $K_k^l$ 越小 → 越信任预测（观测噪声 $R$ 大，或预测已经很准）

2.3 稳态 Kalman 滤波器

对时不变系统 $(A, C)$，Kalman 滤波器的误差协方差会收敛到固定值：

$$P = \lim_{k \to \infty} P_k^l, \qquad \bar{P} = \lim_{k \to \infty} P_k^{l-}$$

其中 $P$ 是更新后的稳态误差，$\bar{P}$ 是预测后的稳态误差。
收敛到稳态后，增益也变成常数：$K = P C^\top (C P C^\top + R)^{-1}$。多数论文（包括我们这篇）直接使用稳态 Kalman 滤波器分析，省去了每个时间步都重新计算增益的麻烦。

🔑 为什么稳态很重要

稳态误差协方差 $P$ 是整个论文分析的性能基准。后续所有比较都会回到这个基准值。具体来说：

  • 传感器本地滤波的误差 = $P$
  • 合法用户收到真实估计后的误差 = 也是 $P$（因为同步了传感器的最优值）
  • 窃听者被噪声毒化后的误差 = 比 $P$ 大很多

3. Q 函数速查

论文中的确定型触发协议会用到标准正态分布的尾部概率——这个函数记为 $Q(\delta)$：

$$Q(\delta) = \int_{\delta}^{\infty} \frac{1}{\sqrt{2\pi}} e^{-t^2 / 2} \, dt$$

它回答的问题是："一个标准正态随机变量 $Z \sim \mathcal{N}(0,1)$ 超过阈值 $\delta$ 的概率是多少？"

💡 直觉

$Q(\delta)$ 就是钟形曲线右尾的面积。$\delta$ 越大，$Q(\delta)$ 越小。在论文中，它用来计算传感器的发送概率。

📐 实用性质

  • $Q(-\delta) = 1 - Q(\delta)$ （对称性）
  • $Q(0) = 0.5$
  • $Q(3) \approx 0.00135$ （三西格玛法则）
  • 没有解析表达式，只能用数值计算或查表

4. 两个算子

论文定义了两个关于矩阵的函数，分别对应 Kalman 滤波器的预测步和更新步。它们会反复出现，务必熟悉：

🔮 预测算子 $h(\cdot)$

$$h(X) = A X A^\top + Q$$

输入当前的误差协方差矩阵 $X$，输出预测后的误差协方差。因为加上了过程噪声 $Q$，不确定性总是变大。

🎯 更新算子 $g(\cdot)$

$$g(X) = X - X C^\top (C X C^\top + R)^{-1} C X$$

输入预测后的协方差，输出更新后的误差协方差。因为利用观测信息，不确定性总是变小（或不变）。

为什么叫"算子"？

因为它们把矩阵映射到矩阵——就像一个函数把数字映射到数字一样。你可以把 $h$ 和 $g$ 看作 Kalman 滤波器的"算术"：

$$P_k^{l-} = h(P_{k-1}^l), \qquad P_k^l = g(P_k^{l-})$$
$$P = g \circ h(P) \quad \text{（稳态条件）}$$

后者 $P = g(h(P))$ 就是稳态 Riccati 方程。$P$ 是这个方程的唯一正定解。

🔑 关键性质

对任意正定矩阵 $X$：

  • $h(X) > X$ （预测增加不确定性）
  • $g(X) \leq X$ （更新减少不确定性）
  • $g(X) = (I - K C) X$，其中 $K = X C^\top (C X C^\top + R)^{-1}$

这里 ">" 和 "≤" 是矩阵不等式：$A > B$ 表示 $A - B$ 正定，$A \leq B$ 表示 $B - A$ 半正定。

5. Lemma 1

Lemma 1 是论文第一个重要引理，它刻画了预测后误差协方差 $\bar{P}$ 和更新后误差协方差 $P$ 之间的差距：

Lemma 1. 令 $P$ 和 $\bar{P}$ 分别为 Kalman 滤波器的稳态误差协方差（更新后）和稳态预测误差协方差（更新前）。则

$$(\bar{P} - P) \geq 0$$
（半正定），且其秩为 $r = \mathrm{rank}(C)$。

进一步，存在正交矩阵 $U$ 使得：

$$U^\top (\bar{P} - P) \, U = \begin{pmatrix} \Lambda & 0 \\ 0 & 0_{n-r} \end{pmatrix}$$

其中 $\Lambda$ 是 $r \times r$ 的正定对角矩阵，包含 $\bar{P} - P$ 的非零特征值。

这个引理在说什么？

  • $\bar{P} - P \geq 0$ 等价于 $\bar{P} \geq P$ ——验证了"预测后 > 更新后"的直觉
  • $\mathrm{rank}(\bar{P} - P) = \mathrm{rank}(C)$ ——差距的大小由观测矩阵决定
  • 如果 $C$ 满秩（$r = n$），那么 $\bar{P} - P$ 也是满秩的——每次观测都带来信息增益
  • 如果 $C$ 秩亏（某些状态不可观测），则 $\bar{P} - P$ 在某些方向上为零——那些方向更新不提供信息

🔑 论文中的用途

Lemma 1 为窃听者噪声中毒分析提供了结构性工具。当窃听者把噪声当作真实估计同步时，它的误差会跳到一个远大于 $P$ 的值。$\bar{P} - P$ 的谱分解帮助量化这个"毒化"程度。

6. 增量创新

Kalman 滤波器每次更新时，估计值的变化量称为增量创新（incremental innovation）：

$$\varepsilon_k = \hat{x}_k^l - A \hat{x}_{k-1}^l = K z_k$$

读作：估计值从"时间更新后"到"观测更新后"的变化量，等于用增益 $K$ 缩放创新 $z_k$。

统计性质

$$\mathbb{E}[\varepsilon_k] = 0$$ $$\mathrm{Cov}(\varepsilon_k) = K Z K^\top$$

其中 $Z = C P_k^{l-} C^\top + R$ 是创新的协方差矩阵。

💡 意义

创新 $z_k$ 代表了"新信息"——观测 $y_k$ 中预测无法解释的部分。如果系统运行正常（模型准确），创新应该是零均值白噪声，即不包含任何可预测的模式。可以说：$z_k$ 就是 Kalman 滤波器的"新鲜度指标"。

论文中，增量创新 $\varepsilon_k$ 会被用来构造编码方案——传感器可以发送 $\varepsilon_k$ 或 $\hat{x}_k^l$，窃听者如果缺少密钥，就无法区分真实创新和伪造噪声。

7. ✏️ 手写练习

理论讲完了，来点具体的。考虑一个标量系统（$n = m = 1$）：

$$A = 0.99, \quad C = 1, \quad Q = 0.25, \quad R = 0.16$$

任务：手算稳态误差协方差 $P$。

解题思路

标量情况下，稳态 Riccati 方程 $P = g(h(P))$ 可以显式求解：

$$P = g(h(P)) = h(P) - \frac{h(P) C^\top C h(P)}{C h(P) C^\top + R}$$ $$\Rightarrow \quad P = (A^2 P + Q) - \frac{(A^2 P + Q)^2}{A^2 P + Q + R}$$

代入数值 $A=0.99$, $Q=0.25$, $R=0.16$：

$$P = (0.9801 P + 0.25) - \frac{(0.9801 P + 0.25)^2}{0.9801 P + 0.25 + 0.16}$$

📝 练习

① 解出 $P$ 的数值（保留 4 位小数）

令 $S = 0.9801 P + 0.25$，代入 Riccati 方程：

$$P = S - \frac{S^2}{S + 0.16} = \frac{S(S+0.16) - S^2}{S+0.16} = \frac{0.16 S}{S+0.16}$$

即 $P(S+0.16) = 0.16 S$。代入 $S = 0.9801 P + 0.25$：

$$P (0.9801 P + 0.25 + 0.16) = 0.16 (0.9801 P + 0.25)$$ $$P (0.9801 P + 0.41) = 0.156816 P + 0.04$$ $$0.9801 P^2 + 0.41 P = 0.156816 P + 0.04$$ $$0.9801 P^2 + 0.253184 P - 0.04 = 0$$

解二次方程：

$$P = \frac{-0.253184 + \sqrt{0.253184^2 + 4 \times 0.9801 \times 0.04}}{2 \times 0.9801}$$ $$P = \frac{-0.253184 + \sqrt{0.064102 + 0.156816}}{1.9602}$$ $$P = \frac{-0.253184 + \sqrt{0.220918}}{1.9602} = \frac{-0.253184 + 0.470019}{1.9602}$$ $$\boxed{P \approx 0.1106}$$
② 计算预测后的稳态误差 $\bar{P} = h(P)$
$$\bar{P} = A^2 P + Q = 0.9801 \times 0.1106 + 0.25$$ $$\bar{P} = 0.1084 + 0.25 = \boxed{0.3584}$$
③ 验证 $\bar{P} > P$ 并计算稳态增益

显然 $\bar{P} = 0.3584 > P = 0.1106$。标量情况下的"秩"就是 1——$\mathrm{rank}(C) = 1$。

稳态 Kalman 增益：

$$K = \frac{\bar{P} C}{C \bar{P} C^\top + R} = \frac{0.3584}{0.3584 + 0.16} = \frac{0.3584}{0.5184} = \boxed{0.6914}$$

更新后的误差：

$$P = (1 - K C) \bar{P} = (1 - 0.6914) \times 0.3584 = 0.3086 \times 0.3584 = \boxed{0.1106}$$

✅ 自洽！

④ 思考：如果 $Q$ 增大到 1.0，$P$ 会怎么变？

$Q$ 增大意味着系统本身的随机性更强，Kalman 滤波器无法准确预测状态走向，因此稳态误差 $P$ 会增大。直观上：你对系统的模型信任度降低了，需要更多地依赖观测——但观测本身也有噪声 $R$，所以整体误差还是上去了。你可以尝试用同样的方法计算 $Q=1.0$ 时的 $P$，比较差异。

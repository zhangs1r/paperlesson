消融实验的关键发现：

  1. 仅 SMOKE 在已知类别动态场景中效果显著（如 KITTI Odometry），但在 KITTI Raw 的未知类别场景中提升有限
  2. 仅交叉视差在慢速动态场景中效果下降（如 1003-0047 序列），但在未知类别场景中表现优异
  3. 完整版在所有序列上一致最优——交叉视差和 SMOKE 联合后的 ATE 总是低于各自单独使用，证明了两者的互补性
  4. 交叉视差 + 加权 BA 比交叉视差 + 硬剔除更好，说明软加权策略确实优于硬决策

3. 失败场景与局限性

论文在结论部分诚实地提到了几个局限性，我们在精读时应该特别注意：

⚠️ 同时出现大量未知动态物体

KITTI Raw 中有一些场景包含训练类别之外的多种动态物体。虽然交叉视差能检测到这些物体上的动态特征点，但如果它们同时出现在视野中太多，交叉视差可能因为"孤立点太多"而难以提供有效约束。

⚠️ 慢速运动场景

1003-0047 序列显示了 OCD SLAM 在慢速场景中的不足。这本质上是交叉视差几何方法的固有局限——帧间位移太小时，任何几何方法都难以区分"噪声"和"真实运动"。

⚠️ SMOKE 的类别局限

SMOKE 只在 KITTI 的三类上训练。应用到其他场景（如室内机器人、校园环境）时，需要重新训练检测器或换用更通用的检测模型。

⚠️ 计算资源需求

虽然比全分割方案轻量，但 SMOKE 推理仍需要 GPU。对于纯 CPU 平台（如部分嵌入式系统），OCD SLAM 的实时性可能受限。

未来工作方向

论文在结论中提出了几个未来方向：

  • 扩展可检测类别：在更多数据集上训练或使用开放词汇检测器
  • 语义 + 几何的更深度融合：不只是"两个模块各自判断再合并"，而是让语义信息和几何信息在特征层面融合
  • 应对更多复杂场景：如夜间、恶劣天气等条件下的动态 SLAM

OCD SLAM 的核心贡献

新几何量

交叉视差（Cross Disparity）利用双目时序 + 立体双不一致性检测动态特征点。

新系统设计

物体级（SMOKE + Kalman）和像素级（交叉视差）双层过滤，盲区互补。

新实证证据

在 KITTI Odometry 和 KITTI Raw 上系统验证了双层互补的有效性。

最终练习

  1. OCD SLAM 提出后，未来如果要进一步提升，你最推荐改进哪个模块？
    展开查看答案
    一个值得尝试的方向：用开放词汇检测器（如 GLIP、Grounding DINO）替换 SMOKE，使物体级检测不受类别限制。这样交叉视差只需专注处理检测器难以处理的情况（慢速运动、非刚体变形等），双层过滤的覆盖范围会更完整。当然，开放词汇检测器的推理速度需要评估是否满足实时要求。
  2. 对比 OCD SLAM 和 DFusion-SLAM，如果让你二选一部署到一台 Jetson Orin 上跑实时 SLAM，你选哪个？为什么？
    展开查看答案
    选 OCD SLAM。原因是：① OCD SLAM 的交叉视差模块纯粹基于几何计算，不消耗 GPU 资源；SMOKE 虽然需要 GPU，但只是单帧推理。② DFusion-SLAM 的语义融合模块需要同时跑检测 + 分割，GPU 负载更重。③ 但要注意：如果目标场景中动态物体以慢速运动为主（如室内环境中缓慢走动的人），OCD SLAM 的表现可能不如 DFusion-SLAM。所以最终选择取决于具体场景。
  3. 学完这六节课后，用你自己的话向同学介绍"交叉视差"，不超过三句话。
    展开查看答案
    交叉视差是一个利用双目相机判断特征点是否在运动的几何方法。它不是直接比较左右图的特征位置，而是把当前帧的信息反投到前一帧的右图上，看投影位置和实际位置是否一致。如果不一致，说明这个点真的动了——不依赖任何先验知识，纯粹靠几何。

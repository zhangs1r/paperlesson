估计器的三阶段记号

记号含义
$\bar q,\bar\Omega$预测后的信息向量与矩阵
$\tilde q,\tilde\Omega$量测更新后、融合前；本文保护的敏感量
$\hat q,\hat\Omega$融合后；估计由解线性方程得到
上标 c / p经典方案 / 本文方案
$\mathcal N_i$论文邻居集合，包含自身
$$\Omega=P^{-1},\quad q=\Omega\hat x,\quad\hat x=\Omega^{-1}q.$$

密码与编码层

记号含义
$\mathcal P_k^i,\mathcal S_k^i$本趟发起者 i 的公钥、私钥；响应者只拿到公钥
$\mathcal O,\mathcal Q_k^i$编码尺度；不要与过程噪声协方差 Q 混淆
$\mathbf E_N$仅编码
$\mathbf E_M,\mathbf E_{NM}$加密 / 编码加密
$\mathbf P_M$编码、加密、解密、解码后的完整往返，输出回到实数尺度
ξ、Ξ、U、T本趟响应者选择的随机掩码与正整数系数
$$H=U+T,\quad\lambda=U/H,\quad\check\varphi=\lambda P_i+(1-\lambda)P_j.$$

最后一式简写量化后的向量为 Pᵢ、Pⱼ，非协方差。接收方算“两个解密解码结果相加 / H”，不直接获得 λ。关系成立须保留量化与拼接条件。

三个不能混淆的界

  • 标量量化误差：绝对值至多 1/(2Q)。
  • 正定矩阵往返误差：半正定序下夹在 ±n/(2Q)I 之间；不是逐元素矩阵界。
  • Theorem 3：平均误差的范数有界，不等于均方误差有界。
$$\mathbb E\|e\|^2=\operatorname{tr}(\operatorname{Cov}(e))+\|\mathbb E e\|^2.$$

汇报前自查

  1. 符号在加密外，不能声称任何信息均不可见。
  2. 未知 U/T 是作者论证的出发点，不是完整形式化协议证明的替代物。
  3. PDF 式 (12) 邻居系数写 λ；按 Algorithm 3 展开应为 1−λ。不要混用两种版本。
  4. 矩阵修正是下界补偿，不是无偏纠错。
  5. 大 Q 不消除随机融合权重，不自动恢复经典 CI。
  6. 次数优势不是字节、延迟与能耗优势。
  7. Fig. 3 是平均误差，Fig. 4 是 AMSE；所有曲线都是有限仿真证据。
